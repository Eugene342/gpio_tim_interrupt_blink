# STM32F446RE: мигание светодиода через прерывание TIM2 (bare-metal)

Bare-metal проект на NUCLEO-F446RE: светодиод на PA5 мигает раз в секунду за счёт прерывания от таймера TIM2. Код написан напрямую через регистры без HAL. Проект демонстрирует работу с прерываниями, расчёт предделителя и перезагрузки таймера и переключение GPIO через регистр BSRR.

## Что реализовано

- Работа на дефолтном HSI 16 МГц без настройки PLL.
- Включение тактирования GPIOA (AHB1) и TIM2 (APB1) вручную.
- Настройка PA5 как выхода (push-pull, без подтяжки).
- Расчёт PSC и ARR для прерывания каждые 1 мс.
- Накопление 1000 прерываний в обработчике → переключение светодиода 1 раз в секунду.
- Разрешение прерывания TIM2 в DIER и NVIC (IRQ №28).
- Переключение светодиода через BSRR с проверкой состояния в ODR.

## Аппаратная часть

- Плата: NUCLEO-F446RE.
- Микроконтроллер: STM32F446RE.
- Светодиод: пользовательский LED на пине PA5.

## Расчёт периода 1 секунды

1. **Тактирование:** HSI 16 МГц, делители шин по умолчанию (AHB = 16 МГц, APB1 = 16 МГц).
2. **TIM2:** делитель APB1 = 1 (не >1), удвоения частоты нет → таймер работает на 16 МГц.
3. **Период прерывания — 1 мс:**  
   `16 000 000 / ((PSC+1) * (ARR+1)) = 1000`  
   Подставляем: `16 000 000 / (16 * 1000) = 1000`.  
   Отсюда: PSC = 15, ARR = 999.
4. **Период переключения:** 1000 прерываний × 1 мс = 1 с.

## Сборка и загрузка

Проект рассчитан на STM32CubeIDE как пустой bare-metal проект:

1. Откройте STM32CubeIDE.
2. Создайте пустой проект для STM32F446RE (без генерации кода CubeMX).
3. Положите `src/main.c` в проект.
4. Убедитесь, что линкер-скрипт соответствует STM32F446RE.
5. Соберите и загрузите через ST-Link.

## Нюансы реализации

- **Флаг прерывания (UIF в SR)** сбрасывается вручную в обработчике: `TIM2->SR &= ~(1U << 0U)`. Без этого прерывание срабатывает повторно сразу после выхода.
- **PSC и ARR** — буферизированные регистры: значения применяются при событии обновления. Поэтому их настраивают до включения таймера (`CEN`).
- **Переключение через BSRR**, а не через ODR напрямую: запись в BSRR атомарна и не требует read-modify-write.
- **NVIC** включается через ISER0 (бит 28 — номер прерывания TIM2).
